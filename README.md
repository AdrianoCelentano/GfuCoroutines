# GfuCoroutines

A Kotlin Coroutines exercise project using the MVI (Model-View-Intent) architecture. This repository contains various exercises across different modules to practice and learn about Kotlin Coroutines in Android, including:

- **Module 2**: Basic coroutines (async/await, coroutineScope, jobs)
- **Module 3**: Coroutine Context and Dispatchers
- **Module 4**: Error handling and Shared Mutable State
- **Module 5**: Asynchronous Flows and Reactive Programming
- **Module 6**: Testing Coroutines

The application provides a hands-on approach to understanding concurrency and reactive programming in Kotlin, providing both the exercises (`ExerciseViewModel`) and the solutions (`SolutionViewModel`).
